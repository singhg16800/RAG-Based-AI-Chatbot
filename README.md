
# RAG-Based AI Chatbot

## Project Overview
This project is an AI-powered chatbot that answers questions based on uploaded PDF documents.

## Technologies Used
- Python
- Streamlit
- Groq API
- PyPDF

## Features
- Upload PDF documents
- Extract text from PDF files
- Divide text into chunks
- Retrieve relevant information using keyword matching
- Generate answers using Groq AI
- Display document sources

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the application:
   streamlit run chatbot.py

3. Enter your Groq API key in the sidebar.
4. Upload and process a PDF.
5. Ask questions about the document.
